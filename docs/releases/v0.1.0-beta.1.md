# Lua Timer Mod 0.1.0-beta.1

First experimental release for Zibo and LevelUp. This is an independent,
optional patch, developed and supported by wahltho. RandomUser agreed to the
adaptation of his Timer Mod.

This version caches identical inputs to two FMS geometry functions for less
than 50 ms of simulator time. It leaves the physics callbacks, `SIM_PERIOD`,
replay handling, W&B and Tablet callbacks unchanged. It does not run complete
scripts at 20 Hz. If a function receives continuously changing inputs, its
cache wrapper removes itself.

The release ZIP supports two installation paths:

- **MTK 0.28.2 or newer:** review your aircraft's patches and select **Lua Timer
  Mod (Beta)**. It is optional and unselected by default for both products.
- **Standalone:** extract the ZIP outside the aircraft folder and follow the
  Python commands in README.md. An overlapping MTK-managed installation is
  blocked; use MTK for files it already manages.

Close X-Plane before installation and restart it afterwards. Keep all receipts
and backups. The original Timer Mod must first be uninstalled through its own
verified backups; this package does not adopt unknown timer edits.

Installer, Lua output/cache tests, native XLua 1/2 callback tests and the MTK
lifecycle matrix cover installation, existing patch combinations, updates,
Repair, removal, Restore and rollback. The test details are in `tests/`.
**Simulator flight and FPS validation remain open. No FPS gain is promised.**
